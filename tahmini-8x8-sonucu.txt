1) BUYUME MODELI (YUKARIDAN-ASAGI, 3 noktali regresyon)

Model: Toplam(N) = A x buyume^(N²)   ->   ln(Toplam) = ln(A) + N² x ln(buyume)
5x5, 6x6, 7x7'nin UCU ile en kucuk kareler fit:

  buyume = 1,7380   (her +1 kare icin ~1,74x carpan)
  A      = 0,014326

  Fit kalitesi (model / gercek):
    5x5 : 14.370        / 12.400        (model %16 fazla)
    6x6 : 6.283.000     / 8.250.272     (model %24 eksik)
    7x7 : 8.296.000.000 / 7.322.035.424 (model %13 fazla)

8x8 = 64 kare:
  Toplam(64) = 0,014326 x 1,7380^64
             = ~33.091.000.000.000   (~33,1 TRILYON)
  7x7 -> 8x8 carpani: ~4.519x

Iki noktali gecis egimleri (kare basina buyume):
  5x5 -> 6x6 : 1,8057
  6x6 -> 7x7 : 1,6857    <- egim YAVASLIYOR

Alternatif senaryolar (ayni veri, farkli varsayim):
  a) son gecisin egimi (1,6857) aynen devam  : ~18,5 trilyon
  b) egimdeki yavaslama lineer devam (1,5558) : ~5,5 trilyon
  c) 3 noktali regresyon (ana tahmin)          : ~33,1 trilyon
